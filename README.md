# Lípidos: del plato a la arteria

Interactivo de apoyo para **Temas Selectos de Química · Unidad III · 3.3 Lípidos** (función biológica, metabolismo, alimentos y riesgos). Preparatoria Xochicalco.

- 8 estaciones con barra de progreso: funciones, viaje de la grasa, HDL y LDL, del refresco al triglicérido, alimentos, inspector de etiquetas, riesgos y quiz, y cierre.
- Las actividades se pueden repetir sin límite; el avance se guarda en el navegador.
- Al final se genera un **comprobante en PNG o PDF** (nombre, grupo, aciertos por actividad y respuesta para el paciente) para subir a Blackboard.
- Un solo archivo (`index.html`), sin dependencias externas.

Caso clínico y etiquetas ficticios, con fines educativos; no sustituye una consulta médica.

Para publicarlo: *Settings → Pages → Deploy from a branch → main / (root)*.
